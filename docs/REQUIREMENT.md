# 要件定義
WeVocalAnalyzer が何を目指し、どこまでできているか。

関連: [README](../README.md)

## 概要
ブラウザ上で音声を解析するツール。スペクトログラム、F0（基本周波数）、フォルマント、強さを波形と並べて表示する。画面を持たないライブラリとしても使え、WeVocalSynth からは追加機能として使う。

## 方針

| 方針 | 理由 |
| --- | --- |
| インストール不要で、ブラウザだけで動く | 気軽に使えることを優先するため |
| 音声ファイルをサーバーへ送らない | 素材の権利やプライバシーを気にせず使用できるようにするため |
| WeVocalSynth と同じ部品で作る | 画面の配置、ステータスバー、下のバーは PevenMUI、波形、ミニマップ、表示範囲は wevocal-lib。再生のボタンは Synth のものを写す。操作感をそろえ、直すところを 1 か所にするため |
| ライブラリ（`src/`）と画面（`app/`）に分ける | Extractor と同じ。Synth の追加機能からライブラリだけを使うため |
| 重い計算は Rust（wasm）と Worker で行う | 画面を止めないため。FFT、STFT、F0 は wevocal-lib のものを使う |

## 機能

### MVP

| 要件 | 内容 | 状態 |
| --- | --- | --- |
| 読み込み | ファイル選択、ドラッグ＆ドロップ。ブラウザで読める形式（AIFF は wevocal-lib が自前で読む） | 済み |
| 波形の表示 | 波形、時間の目盛り、ミニマップ。拡大、縮小、全体表示、再生位置への追従（ツールバー、メニュー、ホイール、スマホの 2 本指） | 済み |
| 再生 | 再生、一時停止、停止、時間の表示（押すと数字を入れて移動）。押すと再生位置を移す。目盛りのドラッグで再生位置を動かし、端では表示範囲を流す | 済み |
| 帯 | 波形、スペクトログラム、F0、強さ（RMS、dBFS、10ms 間隔）を、出すものだけ上から並べる（初めは波形とスペクトログラム）。境目のドラッグで高さの配分を変える | 済み |
| スペクトログラムの縦の拡大 | 見る周波数の範囲を絞る（Alt+ホイール、表示メニュー）。段を切り出すので細かさは変わらない | 済み |
| スペクトル | 右の欄に、選択範囲の平均（なければその時点）のスペクトルを出し、F1〜F3 を縦線で示す | 済み |
| カーソル位置の値 | 時刻、カーソルの高さの周波数と音名（スペクトログラムと F0 の帯）、強さ | 済み |
| 解析の設定 | F0 を探す範囲（下限 40〜150Hz、上限 300〜1500Hz）、フォルマントの最高周波数（5000Hz 男声、5500Hz 女声、8000Hz 子ども。この 2 倍に間引き、次数は kHz＋2）、スペクトログラムの窓の長さ（512〜4096。短いと広帯域、長いと狭帯域）。変えたら解析し直す | 済み |
| 調波の線 | スペクトログラムに F0 の 2〜10 倍の線を重ねる（縞と F0 の推定がそろっているかを見る） | 済み |
| 歌詞の文字化 | Whisper（tiny 約 40MB、base 約 80MB、small 約 250MB から選ぶ）を transformers.js で動かし、区間ごとの時刻と文字を歌詞の帯に並べる。言語は自動か指定。SRT で書き出す。モデルは Hugging Face（onnx-community）から初めて使うときに取得してブラウザに保存する。ONNX Runtime の wasm はアプリと一緒に配り、初めて使ったときに保存する。WebGPU がなければ使えない（開発者向けの設定で CPU を許したときだけ CPU）。ライブラリでは `src/lyrics.ts`（入口を分け、Synth の追加機能には入れない） | 済み |
| CSV の書き出し | 時刻、F0、F1〜F3、強さを 10ms ごとに。選択範囲があればその中だけ。無声区間の F0 とフォルマントは空欄 | 済み |
| 選択範囲 | 帯のドラッグで選ぶ（1 つ）、端のドラッグで調整、すべて選択（Ctrl+A）、選択解除（Esc）、範囲を試聴。右の欄に、範囲の平均 F0（半音で平均）と音名、有声率、平均 F1〜F3、平均の強さを出す | 済み |
| キーとマウス | Space で再生、←→ と Shift で移動、Home と End、Ctrl+O で開く。割り当ては設定で変えられる（PevenMUI の keymap）。ショートカットの一覧 | 済み |
| 画面の作り | WeVocalSynth と同じメニューの並び（ファイル、表示、再生、ヘルプ）、設定（全般、キーとマウス、表示、開発者向け）、テーマ、画面の大きさ、言語、更新の通知、ライセンス情報、このアプリについて | 済み |
| スペクトログラム | STFT 2048 / 256、対数周波数 128 段。周波数の目盛り。Worker で計算し、進み具合をステータスバーに表示する | 済み |
| F0 の表示 | ピッチの帯に F0 の線と C の音名の線を表示する（wevocal-lib の F0 推定、YIN、10ms 間隔） | 済み |
| フォルマントの表示 | F1〜F3 をスペクトログラムに点で重ねる（LPC。約 11kHz に間引き、10ms 間隔）。無声区間は出さない | 済み |
| 値の表示 | カーソルの位置（なければ再生位置）の F0、音名とずれ（セント）、F1〜F3 を右の欄に出す。ピッチの帯とフォルマントの表示を切り替えられる | 済み |
| ライブラリ | `analyzeSpectrogram`、`renderSpectrogram`、`analyzePitch`、`analyzeFormants`。React に依存しない。進み具合と中止は Extractor とそろえる | 済み |

### 対象外（MVP）
編集（ピッチや長さの変更などは WeVocalSynth で行う）、複数トラック。

### MVP の後の候補
- 声の質の指標（Praat の Voice report にあたるもの）: ジッター（周期の揺れ）、シマー（振幅の揺れ）、HNR（調波と雑音の比）。選択範囲で出す
- ビブラートの解析: F0 の揺れの速さ（Hz）と深さ（セント）
- ラベル（注釈）: 時刻や範囲に名前を付け、帯に表示して書き出す（Praat の TextGrid にあたるもの）
- 長時間平均スペクトル（LTAS）、F0 の分布（ヒストグラム）
- ラウドネス（LUFS）、ピーク（dBTP）
- 2 つのファイルの比較（重ねて表示）

## わかっていること
- F0 が高い（高い声など）と、F1 が F0 の近くに出やすい。LPC の山が倍音に引っ張られるため（Praat などでも起きる）。高い声の F1 は目安として見る

## WeVocalSynth との関係
Synth からは追加機能として使う。今のところスペクトログラムだけ。F0、F1 などの API もライブラリからは使えるようにしておき、Synth で使うかは後で決める。

| 項目 | 内容 |
| --- | --- |
| 配り方 | ライブラリ（`src/`）をビルドして `addons/analyzer/` で配る（Extractor と同じ仕組み） |
| Synth での入口 | スペクトログラムの帯を表示するときに導入する |
| 移し終わるまで | Synth のスペクトログラムは今の方式を残し、追加機能に切り替えてから消す |

## 非機能要件

| 項目 | 目標 |
| --- | --- |
| 処理速度 | 数分の曲のスペクトログラムを、数秒で表示する |
| 応答性 | 計算は Worker で行い、画面を止めない。ズームとスクロールでは計算し直さず、画像だけ作り直す |
| 対応環境 | PC とスマホのモダンブラウザ（WebAssembly の SIMD が使えるもの）。オフラインでも使える（PWA） |
