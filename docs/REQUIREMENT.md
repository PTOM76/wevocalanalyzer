# 要件定義
WeVocalAnalyzer が何を目指し、どこまでできているか。

関連: [README](../README.md)

## 概要
ブラウザ上で声を解析するツール。スペクトログラム、F0（ピッチ）、フォルマントを波形と並べて表示する。画面を持たないライブラリとしても使え、WeVocalSynth からは追加機能として使う。

## 方針

| 方針 | 理由 |
| --- | --- |
| インストール不要で、ブラウザだけで動く | 気軽に使えることを優先するため |
| 音声ファイルをサーバーへ送らない | 素材の権利やプライバシーを気にせず使用できるようにするため |
| WeVocalSynth と同じ部品で作る | 画面の配置、ステータスバー、下のバーは PevenMUI、波形、ミニマップ、表示範囲は wevocal-lib。再生のボタンは Synth のものを写す。操作感をそろえ、直すところを 1 か所にするため |
| ライブラリ（`src/`）と画面（`app/`）に分ける | Extractor と同じ。Synth の追加機能からライブラリだけを使うため |
| 重い計算は Rust（wasm）と Worker で行う | 画面を止めないため。FFT、STFT、F0 は wevocal-lib のものを使う |

## 機能

### MVP

| 要件 | 内容 | 状態 |
| --- | --- | --- |
| 読み込み | ファイル選択、ドラッグ＆ドロップ。ブラウザで読める形式（AIFF は wevocal-lib が自前で読む） | 済み |
| 波形の表示 | 波形、時間の目盛り、ミニマップ。拡大、縮小、全体表示、再生位置への追従（ツールバー、メニュー、ホイール、スマホの 2 本指） | 済み |
| 再生 | 再生、一時停止、停止、時間の表示（押すと数字を入れて移動）。波形を押す、ドラッグすると再生位置を動かし、端では表示範囲を流す | 済み |
| キーとマウス | Space で再生、←→ と Shift で移動、Home と End、Ctrl+O で開く。割り当ては設定で変えられる（PevenMUI の keymap）。ショートカットの一覧 | 済み |
| 画面の作り | WeVocalSynth と同じメニューの並び（ファイル、表示、再生、ヘルプ）、設定（全般、キーとマウス、表示、開発者向け）、テーマ、画面の大きさ、言語、更新の通知、ライセンス情報、このアプリについて | 済み |
| スペクトログラム | STFT 2048 / 256、対数周波数 128 段。周波数の目盛り。Worker で計算し、進み具合をステータスバーに表示する | 済み |
| F0 の表示 | ピッチの帯に F0 の線と C の音名の線を表示する（wevocal-lib の F0 推定、YIN、10ms 間隔） | 済み |
| フォルマントの表示 | F1〜F3 をスペクトログラムに点で重ねる（LPC。約 11kHz に間引き、10ms 間隔）。声のない区間は出さない | 済み |
| 値の表示 | カーソルの位置（なければ再生位置）の F0、音名とずれ（セント）、F1〜F3 を右の欄に出す。ピッチの帯とフォルマントの表示を切り替えられる | 済み |
| ライブラリ | `analyzeSpectrogram`、`renderSpectrogram`、`analyzePitch`、`analyzeFormants`。React に依存しない。進み具合と中止は Extractor とそろえる | 済み |

### 対象外（MVP）
歌詞の文字化、編集（ピッチや長さの変更などは WeVocalSynth で行う）、複数トラック。

### MVP の後の候補
- 周波数の解析（選択範囲の平均のスペクトル）、カーソル位置の数値、CSV の書き出し
- 歌詞の文字化（Whisper などの ONNX。Analyzer の画面だけで使い、Synth には入れない）
- 選択範囲（選択範囲の値の平均、選択範囲の再生）

## わかっていること
- 声が高いと、F1 が F0（基本の高さ）の近くに出やすい。LPC の山が倍音に引っ張られるため（Praat などでも起きる）。高い声の F1 は目安として見る

## WeVocalSynth との関係
Synth からは追加機能として使う。今のところスペクトログラムだけ。F0、F1 などの API もライブラリからは使えるようにしておき、Synth で使うかは後で決める。

| 項目 | 内容 |
| --- | --- |
| 配り方 | ライブラリ（`src/`）をビルドして `addons/analyzer/` で配る（Extractor と同じ仕組み） |
| Synth での入口 | スペクトログラムの帯を表示するときに導入する |
| 移し終わるまで | Synth のスペクトログラムは今の方式を残し、追加機能に切り替えてから消す |

## 非機能要件

| 項目 | 目標 |
| --- | --- |
| 処理速度 | 数分の曲のスペクトログラムを、数秒で表示する |
| 応答性 | 計算は Worker で行い、画面を止めない。ズームとスクロールでは計算し直さず、画像だけ作り直す |
| 対応環境 | PC とスマホのモダンブラウザ（WebAssembly の SIMD が使えるもの）。オフラインでも使える（PWA） |
