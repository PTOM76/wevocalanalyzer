# WeVocalAnalyzer
WeVocalAnalyzer は、Web ブラウザで音声を解析するツールである。波形、スペクトログラム、F0（基本周波数）、フォルマント、強さを並べて表示する。<br />
インストールは不要。音声ファイルはサーバーへ送らず、処理はすべてブラウザ内で行う。

- ソースコード: https://github.com/PTOM76/wevocalanalyzer

## はじめに
1. アプリを開き、音声ファイルを画面にドラッグ＆ドロップする（または「ファイル」→「開く…」）
2. 波形とスペクトログラムを見る。出したい帯は「表示」メニューで増やす
3. カーソルを動かすと、その位置の F0、フォルマント、強さが右の欄に表示される

詳しくは [基本の流れ](basics.md) を参照。言葉の意味は [用語](glossary.md) にまとめている。

## できること
| 分類 | 機能 |
| --- | --- |
| 表示 | 波形、スペクトログラム（フォルマント F1〜F3 を重ねる、縦の拡大）、F0、強さの帯。ミニマップ |
| 値 | カーソルや選択範囲の F0、音名、F1〜F3、強さ、スペクトル、F0 の分布、LTAS、ラウドネス、声の質、ビブラート |
| 歌詞 | Whisper で歌詞を文字にし、日本語は読み（ひらがな）を付ける。一音ずつの境目も求める |
| 比較 | 2 つの音声（加工の前後など）の F0、強さ、スペクトルを重ねて比べる |
| ラベル | 範囲や点にメモを付け、Praat の TextGrid などで書き出す |
| 書き出し | 解析結果を CSV で、歌詞を SRT で |
| その他 | パソコンとスマホに対応、オフラインで使用できる、ライト / ダーク、日本語、英語、韓国語、中国語 |
