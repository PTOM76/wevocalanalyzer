# キーボード操作
キーボードで使用できる操作の一覧。

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 再生位置を戻す / 進める。Shift で細かく |
| Home / End | 先頭へ / 最後へ |
| Ctrl+A | すべて選択 |
| Esc | 選択を解除 |
| Ctrl+O | ファイルを開く |
| Ctrl+B | ラベルを付ける |
| Tab | 比較の音声と切り替える |
| Alt / F10 | メニューバーに移動する |

割り当ては設定の「キーとマウス」で変えられる。一覧は「ヘルプ」→「ショートカット一覧」でも確認できる。
