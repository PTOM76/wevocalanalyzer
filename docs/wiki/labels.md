# ラベル
音の位置や範囲にメモを付ける機能。

音の位置や範囲に、メモを付ける。

| 操作 | 内容 |
| --- | --- |
| 「ツール」→「選択範囲にラベルを付ける」（Ctrl+B） | 選択範囲にラベルを付ける。範囲がなければ再生位置に点のラベルを付ける |
| 「ツール」→「ラベルの一覧…」 | 文字を直す、範囲を選ぶ、消す |
| 「ファイル」→「ラベルを TextGrid で書き出し…」 | Praat で開ける形式（範囲は IntervalTier、点は TextTier） |
| 「ファイル」→「ラベルをテキストで書き出し…」 | タブ区切りのテキスト。音声編集ソフトのラベルとして読み込める |

別のファイルを開くと、ラベルは消える。
