# 使い方
WeVocalAnalyzer の操作方法をまとめた説明書。<br />
音声ファイルを開き、波形、スペクトログラム、F0（基本周波数）、フォルマント、強さを見て、歌詞の文字化や2つの音声の比較をするまでの流れと、各機能の使い方を記載する。

## 用語

| 用語 | 意味 |
| --- | --- |
| スペクトログラム | 音を周波数ごとに分けて、時間の流れとともに色の濃さで表した図 |
| F0 | 基本周波数。声の高さにあたる |
| フォルマント | 声の響きの山。低い方から F1、F2、F3 と呼ぶ。母音の違いに関係する |
| 帯 | 波形、スペクトログラムなどを、時間をそろえて縦に並べた1段ずつ |
| LTAS | 長時間平均スペクトル。曲全体の周波数ごとの音量の平均 |
| ジッター、シマー | 声の周期と大きさの細かいゆらぎ。声のかすれやすさの目安 |
| HNR | 声の中の、周期的な成分と雑音の比 |
| LUFS | 音の大きさの感じ方に合わせた単位 |
| dBTP | トゥルーピーク。再生時に音が割れる恐れのある最大値 |

## 基本の流れ

1. **開く**: 音声ファイルを画面にドラッグ＆ドロップするか、「ファイル」→「開く…」（Ctrl+O）で選択する
2. **見る**: 波形とスペクトログラムが表示される。ホイールで拡大縮小し、ドラッグで位置を移す。出したい帯は「表示」メニューで増やす
3. **値を読む**: カーソルを動かすと、その位置の F0、フォルマント、強さが右の欄に表示される。範囲を選ぶと、その範囲の平均などが表示される
4. **書き出す**: 「ファイル」から、解析結果の CSV、歌詞の SRT、ラベルの TextGrid を保存する

## 対応ファイル

| 種類 | 例 |
| --- | --- |
| 音声ファイル | WAV、AIFF、MP3、M4A（AAC）、FLAC、Ogg など（ブラウザによって読み込めない形式がある） |
| 動画ファイル | MP4（音声のみを使用する） |
| WeVocalSynth のプロジェクト | .wvsp。編集していたトラックの加工後の音を開く。トラックが 2 本以上あるときは、ツールバーで選ぶ |

## 波形の操作

| 操作 | 動作 |
| --- | --- |
| ホイール | 拡大縮小と横スクロール（設定の「キーとマウス」で、ホイールだけで拡大縮小するか、Ctrl+ホイールかを選ぶ） |
| Alt+ホイール | スペクトログラムの縦（周波数）の拡大縮小 |
| 波形を押す | 再生位置をその位置に移す |
| 目盛りのドラッグ | 再生位置を動かす。端では表示範囲が流れる |
| 2 本指（スマホ） | 拡大縮小 |
| 時間の表示を押す | 数字を入力して移動する |
| ツールバー、「表示」メニュー | 拡大、縮小、全体表示、再生位置への追従、縦の拡大 |
| ミニマップ | 全体の中の表示範囲を示す。ドラッグで移動する |

## 帯の表示

波形、スペクトログラム、F0（ピッチ）、強さを、表示するものだけ上から並べる（初めは波形とスペクトログラム）。境目をドラッグすると、高さの配分を変えられる。

| 帯 | 内容 |
| --- | --- |
| 波形 | 音の大きさの形 |
| スペクトログラム | 周波数ごとの強さ。縦軸は対数の周波数 |
| F0（ピッチ） | F0 の線と、C の音名の線 |
| 強さ（RMS） | 10ms ごとの音量（dBFS） |
| 歌詞 | 文字化した歌詞と読み |
| ラベル | 付けたラベル |

スペクトログラムには、次のものを重ねられる。

| 重ねるもの | 内容 |
| --- | --- |
| フォルマント | F1〜F3 を点で重ねる。無声の区間は表示しない |
| 調波の線 | F0 の 2〜10 倍の線。縞と F0 の推定がそろっているかを見る |

- 高い声では、F1 が F0 の近くに表示されやすい。解析の山が倍音に引っ張られるためで、Praat などでも起きる。高い声の F1 は目安として見る

## 右の欄の値

カーソルの位置（なければ再生位置）の値と、全体の値が表示される。

| 項目 | 内容 |
| --- | --- |
| F0、音名 | カーソル位置の F0 と、音名とのずれ（セント） |
| F1〜F3 | カーソル位置のフォルマント |
| 強さ | カーソル位置の音量 |
| カーソルの高さの周波数 | スペクトログラムと F0 の帯で、カーソルの高さの周波数と音名 |
| スペクトル | 選択範囲の平均（なければその時点）。F1〜F3 を縦線で示す |
| F0 の分布 | 半音ごとの棒グラフ。音域と、最も多い音。選択範囲があればその中だけ |
| LTAS | 全体の長時間平均スペクトル |
| ラウドネス | 全体と選択範囲の統合ラウドネス（LUFS）とトゥルーピーク（dBTP） |

## 選択範囲

| 操作 | 動作 |
| --- | --- |
| 帯のドラッグ | 範囲を選ぶ（1 つ）。端のドラッグで調整する |
| Ctrl+A | すべて選択する |
| Esc | 選択を解除する |
| 「再生」→「範囲を試聴」 | 選択範囲だけを再生する |

選択範囲があると、右の欄に次の値が表示される。

| 項目 | 内容 |
| --- | --- |
| 平均 F0 | 半音で平均した F0 と音名 |
| 有声率 | 声のある部分の割合 |
| 平均 F1〜F3 | フォルマントの平均 |
| 平均の強さ | 音量の平均 |
| 声の質 | ジッター、シマー、HNR。10 秒までの範囲で表示する。伸ばした母音を選ぶと値が安定する |
| ビブラート | 速さ（Hz）と深さ（±セント）。3〜10Hz で ±10 セント以上のものだけ表示し、なければ「なし」 |

## 歌詞の文字化

「ツール」→「歌詞を文字化…」で、Whisper を使って歌詞を文字にし、歌詞の帯に区間ごとに並べる。

| 項目 | 内容 |
| --- | --- |
| モデル | tiny（約 120MB、速い）、base（約 200MB）、small（約 560MB、正確） |
| 言語 | 自動で判定、または日本語、英語、韓国語、中国語から指定する |
| 読み | 日本語の区間には、読み（ひらがな）を付ける |
| 実行 | WebGPU が必要。使用できないブラウザでは押せない。設定の「開発者向け」で CPU を許すと CPU で動くが、とても時間がかかる |

- 伴奏のある曲は、先にボーカルを取り出すと精度が上がる（[WeVocalExtractor](https://github.com/PTOM76/wevocalextractor)）
- 文字化の処理とモデルは追加機能。初めて使うときに導入のダイアログが表示され、ダウンロードする。2 回目以降はダウンロードしない。設定の「解析」から削除できる
- 「ツール」→「歌詞と読みを編集…」で、区間ごとに歌詞と読みを直せる。読みはひらがなで入力する
- 「ツール」→「一音ずつに分ける」で、読みの一音ずつの境目を求める。分けきれないところは均等に分け、「確かでない」印を付ける
- 「ファイル」→「歌詞を SRT で書き出し…」で、字幕のファイルにできる

## 比較

2 つの音声（たとえば加工の前後）の F0、強さ、スペクトルを並べて比べる。

| 操作 | 内容 |
| --- | --- |
| 「ファイル」→「比較する音声を開く…」 | 2 つ目の音声を、同じ設定で解析する |
| 「加工前の音と比較する」 | .wvsp を開いているときに表示される。加工前の音と比べる |
| 「ほかのトラックと比較する」 | .wvsp のほかのトラックと比べる |
| 「比較を閉じる」 | 比較をやめる |
| Tab | A と比較の音声を、同じ位置のまま切り替えて聴く |

「表示」メニューで、次を切り替えられる。

- 比較の帯（波形、スペクトログラム）
- 波形の重ね描き
- スペクトログラムの差（A − 比較。橙が A の方が強く、青が比較の方が強い）

右の欄には、ずらす量（秒）と「自動でそろえる」（強さの相互相関で位置を合わせる）、比較の F0 と差（セント）、スペクトル、LTAS、F0 の分布の重ね描きが表示される。部分ごとの伸び縮みには合わせない。

## ラベル

音の位置や範囲に、メモを付ける。

| 操作 | 内容 |
| --- | --- |
| 「ツール」→「選択範囲にラベルを付ける」（Ctrl+B） | 選択範囲にラベルを付ける。範囲がなければ再生位置に点のラベルを付ける |
| 「ツール」→「ラベルの一覧…」 | 文字を直す、範囲を選ぶ、消す |
| 「ファイル」→「ラベルを TextGrid で書き出し…」 | Praat で開ける形式（範囲は IntervalTier、点は TextTier） |
| 「ファイル」→「ラベルをテキストで書き出し…」 | タブ区切りのテキスト。音声編集ソフトのラベルとして読み込める |

別のファイルを開くと、ラベルは消える。

## 書き出し

| 項目 | 内容 |
| --- | --- |
| 解析結果（CSV） | 「ファイル」→「解析結果を CSV で書き出し…」。時刻、F0、F1〜F3、強さを 10ms ごとに書く。無声の区間の F0 とフォルマントは空欄 |
| 選択範囲の解析結果（CSV） | 選択範囲があるとき、その範囲だけを書き出す |
| 歌詞（SRT） | 歌詞の文字化をしたあと |
| ラベル | TextGrid、テキスト |

## 設定

「ファイル」→「設定…」（スマホは「⋮」→「ヘルプ」→「設定…」）。

| 分類 | 項目 |
| --- | --- |
| 全般 | テーマ（システムに合わせる、ライト、ダーク）、言語、画面の大きさ、アップデートの確認 |
| キーとマウス | ホイールの操作（ホイールだけで拡大縮小するか、Ctrl+ホイールか）、キーの割り当て |
| 解析 | F0 の範囲、フォルマント、スペクトログラムの窓の長さ（下の表）。歌詞の文字化の追加機能とモデルの導入、削除 |
| 開発者向け | 歌詞の文字化を CPU でも行う、開発版の更新を受け取る、追加機能を選んだフォルダーに保存する、ダイアログの表示 |

解析の設定は、変えると解析し直される。

| 項目 | 内容 |
| --- | --- |
| F0 を探す範囲 | 下限 40〜150Hz、上限 300〜1500Hz。範囲が合っていないと、1 オクターブ違う値になることがある。男声は 60〜300Hz、女声は 100〜600Hz が目安 |
| フォルマントの最高周波数 | 5000Hz（男声）、5500Hz（女声）、8000Hz（子ども）。一般的には男声 5000Hz、女声 5500Hz |
| スペクトログラムの窓の長さ | 512〜4096 サンプル。短いと時間の分解能が上がり、フォルマントが見やすい。長いと周波数の分解能が上がり、倍音が見やすい |

## キーボード操作

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 再生位置を戻す / 進める。Shift で細かく |
| Home / End | 先頭へ / 最後へ |
| Ctrl+A | すべて選択 |
| Esc | 選択を解除 |
| Ctrl+O | ファイルを開く |
| Ctrl+B | ラベルを付ける |
| Tab | 比較の音声と切り替える |
| Alt / F10 | メニューバーに移動する |

割り当ては設定の「キーとマウス」で変えられる。一覧は「ヘルプ」→「ショートカット一覧」でも確認できる。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| F0 が 1 オクターブずれる | 設定の「解析」で、F0 を探す範囲を声に合わせる |
| 高い声の F1 が F0 に近い | 解析の性質で起きる。目安として見る |
| フォルマントが見づらい | スペクトログラムの窓の長さを短くする。声に合わせてフォルマントの最高周波数も変える |
| 歌詞の文字化を押せない | WebGPU が使用できないブラウザ。設定の「開発者向け」で CPU を許す |
| 歌詞の精度が低い | 先にボーカルだけを取り出した音声で試す。モデルを大きくする |
| ファイルを開けない | WAV か MP3 に変換してから開く |
